# Bright Steps (Fabric, Minecraft 1.21.11)
Увеличивает и делает ярче частицы бега по блокам.

## Сборка
Вариант 1 (локально): JDK 21, затем в папке проекта
  gradle wrapper --gradle-version 9.2.1
  ./gradlew build        (Windows: gradlew.bat build)
Вариант 2 (без установки): залейте проект на GitHub, вкладка Actions → build → Artifacts.
Готовый jar: build/libs/bright-steps-1.0.0.jar (не берите -sources).

## Нужно у игрока
Fabric Loader 0.18.5+, Fabric API 0.141.4+1.21.11.
Для экрана настроек: Mod Menu 17.0.0 + Cloth Config 21.11.153 (необязательно).

## Настройки
Mod Menu → Bright Steps, либо файл config/brightsteps.json.
